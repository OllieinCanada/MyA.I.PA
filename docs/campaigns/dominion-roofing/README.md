# Dominion Roofing outreach package

This folder contains a private, fact-checked My AI PA outreach concept prepared for Dominion Roofing and a Gmail-safe test email.

## Files

- `index.html` — responsive public landing page
- `flyer.html` — 1200 × 1500 flyer source used to render the preview image
- `flyer-preview.png` — standalone shareable flyer
- `email.html` — Gmail-safe HTML email using tables and inline styles
- `email.txt` — plain-text fallback
- `campaign.json` — campaign details, pricing, links, example lead, and send guard
- `research.md` — verified facts and official sources
- `assets/hero.jpg` — original AI-generated roofing image; no company logo or copied photography
- `assets/email-flyer.jpg` — optimized email image linked to the tailored page
- `dominion-roofing-campaign.zip` — downloadable copy of the complete campaign package

## Safety and send rule

This test may be sent only to `olliefromcanada@gmail.com`. No Dominion Roofing email address is stored in the package. The subject and body are intentionally written as a realistic message to the Dominion Roofing team.
