Cookie & browser storage notice

Last reviewed August 25, 2026

The current My AI PA website uses limited browser storage to secure accounts, protect signup, remember a few choices, and keep the site working reliably.

No advertising trackers were identified in the current website code. My AI PA does not currently load third-party advertising pixels or marketing analytics on its public pages. This notice must be reviewed again before any such tool is added.

What the site uses

TechnologyPurposeTypical duration
Secure session cookiesKeep an authorized administrator or customer signed in. The server marks these cookies HttpOnly and SameSite=Lax, and Secure in production.Up to 12 hours, or until cleared or signed out.
Session storageRemember customer-dashboard lookup details within the current browser tab so the user does not need to re-enter them during that visit.Until the tab or browser session ends, or the user signs out.
Local storageCount recent signup attempts for abuse protection and remember the optional demo-game best score on that device.Signup-attempt entries are used within a one-hour window. The optional score remains until browser data is cleared.
Service-worker cacheStore selected public site files so updates and repeat visits work reliably. The cache is versioned and older versions are removed.Until replaced by a newer site version or browser data is cleared.

Choices and controls

You can clear cookies, site data, or cached files using your browser settings. Blocking essential session storage may prevent sign-in, dashboard, signup-protection, or offline/reload features from working correctly.

The optional game score can be removed by clearing site data. It is not used to build an advertising profile.

Third-party sites

If you choose to open a hosted payment, calendar, or other provider page, that provider may use its own cookies under its own notice. My AI PA does not control storage set after you leave this website.

If the technology changes

Before adding non-essential advertising or marketing analytics, My AI PA must update this notice and add a consent choice where required. The broader handling of personal information is described in the Privacy Policy.
